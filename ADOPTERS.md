# Adopters

People and organisations that use ai-sandbox. If that is you, add a line (pull request) or open an issue
titled **"We use ai-sandbox"**.

Nothing in the license requires this. It is the acknowledgement the author asks for in return for the free
license, and it is what keeps an open-source project alive: it shows which tools, platforms and workflows the
project has to keep working, it is the reference list that gets other people and companies to trust it, and it
is how the maintainer decides what to do first.
